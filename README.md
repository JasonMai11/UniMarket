# UniMarket

UniMarket is an iOS marketplace app designed for university students to buy and sell items within their university community.

## Features

- User authentication and registration
- Create and manage listings
- Browse items by university
- Real-time messaging between buyers and sellers
- Image upload and management
- Search functionality
- Item categorization and condition tracking

## Requirements

- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+
- Firebase account

## Setup

1. Clone the repository
2. Open `UniMarket.xcodeproj` in Xcode
3. Add your Firebase configuration file (`GoogleService-Info.plist`)
4. Build and run the project

## Dependencies

- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- SwiftUI

## Architecture

The app follows the MVVM (Model-View-ViewModel) architecture pattern and uses SwiftUI for the user interface.
